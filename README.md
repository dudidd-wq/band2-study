# Band II – לומדים מילים באנגלית 🇬🇧➜🇮🇱

אפליקציית ווב סטטית (בלי שרת) ללימוד רשימת אוצר המילים הרשמית של משרד החינוך
**Lexical Band II** – ‏2016 מילים וביטויים (Core I + Core II) עם תרגום לעברית
והקראה בקול: **Matilda** באנגלית ו-**Tomer** בעברית.

האפליקציה כולה בעברית, מימין לשמאל, מותאמת קודם כול לטלפון, ואפשר להתקין אותה
כאפליקציה (PWA) שעובדת גם בלי אינטרנט.

## מה יש בפנים

### 📚 צפייה ושמיעה
- 20 חלקים של 100–102 מילים. החלוקה זהה לסרטונים: Core I בחלקים 1–10 ו-Core II בחלקים 11–20.
- כרטיס לכל מילה: המילה באנגלית, חלק הדיבר, רמז המשמעות הרשמי, התרגום לעברית,
  כפתורי השמעה (EN / עב), סימון ✅ "יודעת" ו-⭐ "קשה".
- חיפוש מילה באנגלית או בעברית, סינון לפי מצב (חדשות / בלמידה / שלטת / קשות),
  ואפשרות להסתיר את התרגום כדי לבדוק את עצמך.
- **כרטיסיות**: לוחצים כדי להפוך את הכרטיס, ואז עונים "ידעתי" או "לא ידעתי". אפשר אנגלית→עברית או עברית→אנגלית, לפי הסדר או מעורבב.
- **מצב האזנה** (🎧), באותה שיטה כמו בסרטונים: מילה באנגלית ← הפסקת היזכרות עם ספירה לאחור ←
  התרגום בעברית ← הפסקת חזרה ("חזרי בקול!"). כל 25 מילים יש חזרה מהירה.
  אורך ההפסקות והמהירות ניתנים לשינוי. יש הפעלה/השהיה/דילוג, ואפשר לשלוט גם ממסך הנעילה ומהאוזניות (Media Session).
  ההפסקות עצמן מושמעות כקטעי שקט באותו נגן, ולכן ההאזנה ממשיכה גם כשהמסך כבוי.

### ✍️ בחינה עצמית
- סוגי שאלות: אמריקאית אנגלית→עברית, אמריקאית עברית→אנגלית, **שמיעה** (שומעים ובוחרים פירוש),
  **הקלדה** (מקלידים את המילה באנגלית) ו**מעורב**.
- בחירת מילים: חלק, טווח מספרים, חזרות להיום, מילים קשות בלבד, תרגול מעורב או כל הרשימה.
- בדיקת ההקלדה סלחנית: לא משנה אם יש אותיות גדולות, `sb`/`sth`, סימני פיסוק או מילים בסוגריים. כל חלופה של `a/b` או `X or Y` מתקבלת, וגם טעות הקלדה אחת במילה ארוכה. מילה אנגלית אחרת (למשל quiet במקום quite) לא נחשבת טעות הקלדה, ומילה נרדפת מהרשימה עם אותו תרגום (continue / carry on) מתקבלת.
- משוב מיידי עם צליל והשמעת המילה, ובסוף מסך סיכום שבו אפשר לתרגל שוב רק את הטעויות.

### 📈 מעקב למידה
- חזרה מרווחת בשיטת **לייטנר**: תשובה נכונה מקדמת את המילה לתיבה הבאה, והחזרה הבאה מתרחקת (1, 2, 4, 8, 16 ו-32 ימים). טעות מחזירה את המילה לתיבה 1.
  מילה בתיבה 4 ומעלה נחשבת "שלטת".
- לוח מעקב: שלטת / בלמידה / חדשות, רצף ימים ושיא, דיוק ב-30 הימים האחרונים (גרף SVG),
  ימי פעילות, התקדמות לכל חלק, תור "חזרות להיום" ותחזית לשבוע הקרוב.
- ייצוא וייבוא של ההתקדמות כקובץ JSON (למשל כדי לעבור לטלפון אחר), ואיפוס.
- הכול נשמר **רק במכשיר** (localStorage). אין שרת, אין חשבון ואין מעקב.

## איך משתמשים
1. פותחים את הקישור בטלפון (Chrome באנדרואיד או Safari באייפון).
2. **התקנה**: באנדרואיד, תפריט ⋮ ← "הוספה למסך הבית" / "התקנת אפליקציה". באייפון, כפתור השיתוף ← "הוספה למסך הבית".
3. כדי להשתמש בלי אינטרנט: בדף של כל חלק יש כפתור "⬇️ שמירה לשימוש בלי אינטרנט", ששומר את כל קובצי השמע של החלק.
   גם שמע שכבר הושמע נשמר אוטומטית.
4. שגרה מומלצת: 10–15 דקות ביום. קודם "חזרות להיום" (🔁 בפינה), ואז חלק חדש:
   צפייה ← האזנה ← כרטיסיות ← בחינה.

## הפעלה ב-GitHub Pages
1. דוחפים את הריפו ל-GitHub (למשל `band2-study`):
   ```bash
   git remote add origin git@github.com:<USER>/band2-study.git
   git push -u origin main
   ```
2. ב-GitHub: **Settings ← Pages ← Build and deployment**. בוחרים **Source: Deploy from a branch**,
   ואז **Branch: `main`** ותיקייה **`/ (root)`**, ושומרים.
3. אחרי דקה-שתיים האתר זמין בכתובת `https://<USER>.github.io/band2-study/`.
   כל הנתיבים יחסיים, כך שהאתר עובד גם מתת-תיקייה. אין שלב build.

## בנייה מחדש של הנתונים והשמע (למפתחים)
הנתונים והשמע נוצרו מתיקיית הפרויקט המקורית (`/workspace/band2`) **בלי אף קריאת API**.
הסקריפט מחשב מחדש את שם הקובץ במטמון ה-TTS לכל מילה, עם אותה נורמליזציה של `tts.py`:
`sha1("eleven_v4|voice|lang|text")[:16]`. אחר כך הוא חותך שקט, מנרמל עוצמה ומקודד ל-MP3 קטן.
```bash
python3 tools/build_data.py /workspace/band2   # data/words.json + audio/en, audio/he
python3 tools/check_assets.py                  # כל קובצי השמע קיימים?
node tools/test-match.mjs                      # בדיקות להשוואת ההקלדה
# בדיקת דפדפן (headless):
python3 -m http.server 8765 &
npm i --no-save playwright-core
node tools/smoke-test.mjs http://localhost:8765/ /usr/bin/google-chrome
```
אם לאחת המילים אין קובץ שמע (`a` בלי הביט המתאים), האפליקציה עוברת אוטומטית להקראה של הדפדפן (speechSynthesis).
כרגע **לכל 2016 המילים יש שמע מוקלט** בשתי השפות.

**רמזי אימוג׳י:** לכל מילה יש אימוג׳י אחד (שדה `e` ב-`data/words.json`, ועותק ב-`data/emoji_hints.json`) שרומז על המשמעות בלי לגלות את התרגום.
הבחירה ידנית ב-`tools/emoji/curated_*.txt` (שורה `n emoji`), והבנייה עם `node tools/build_emoji.mjs` – הסקריפט בודק שכל ערך הוא גרפים אימוג׳י יחיד, בלי אותיות/דגלים, ומשלים מילים חסרות לפי מילות מפתח (ו-💡 כמוצא אחרון).
מוצג: בחזית הכרטיסייה (אנגלית ← עברית) ולצד העברית אחרי ההיפוך, במצב האזנה בזמן ספירת ההיזכרות, ברשימת המילים (גם כשהתרגום מוסתר), ובבחינה רק בלחיצה על "🫣 רמז ציורי" (לא משפיע על הציון). אפשר לכבות במסך המעקב → הגדרות.
בדיקה: `node tools/smoke-emoji.mjs http://localhost:8765/` (412×915).

**משפטי שיחה** (`#/sentences`, גם מתוך מסך הבחינה): 160 משפטים (8 לכל חלק) בשלושה סוגים – השלמת מילה (80), בניית משפט בהקשה או גרירה (40), ודיאלוג קצר (40).
התוכן נכתב ידנית ב-`tools/sentences/content.py`, ונבנה ל-`data/sentences.json` עם `python3 tools/sentences/build_sentences.py`. הסקריפט בודק שמילת היעד שייכת לחלק, שיש בדיוק חסר אחד, שהמסיחים הם מילים מאותו חלק, ושכל מילה אחרת היא מילה בסיסית או מילת Band II מחלק קודם.
כל תשובה מעדכנת את מעקב הלמידה (Leitner) של מילת היעד. בדיקה: `node tools/smoke-sentences.mjs http://localhost:8765/` (412×915).

**עדכון גרסה:** אחרי שינוי בקוד מעלים את `VERSION` ב-`sw.js`, כדי שהטלפונים יקבלו את הגרסה החדשה.
